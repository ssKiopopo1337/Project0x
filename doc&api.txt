01
Быстрый старт
От создания файла до первого текста на экране — пять минут. Всё, что нужно, уже есть в клиенте: редактор скриптов живёт во вкладке Extensions.

#
Создание и загрузка скрипта
1
Открой вкладку Extensions в меню клиента.
2
Нажми +, укажи имя скрипта и вставь Lua-код.
3
Нажми Save, чтобы просто сохранить, или Save & Reload, чтобы сохранить и сразу загрузить. У уже существующего скрипта редактор открывается кнопкой ….
4
Список скриптов обновляется кнопкой Refresh; кнопки загрузки и остановки находятся рядом с каждым скриптом.
Готовый скрипт с диска

Скопируй нужный .lua в C:\neverwin\scripts и нажми Refresh в Extensions — файл появится в списке. Путь neverwin — действующий каталог текущей сборки, он не переименовывался.

#
Минимальный пример
hello.lua
lua
Копировать
print("Script loaded")

events.on("paint", function()
    render.text(24, 90, color(255, 255, 255), "Hello, Lua!")
end)
print пишет в вывод Lua и срабатывает при загрузке скрипта. Обработчик paint вызывается каждый кадр отрисовки — именно внутри него разрешены все функции render.*. Цвет собирается конструктором color(r, g, b, a), каналы — от 0 до 255.

Первый элемент меню
overlay.lua
lua
Копировать
local tab = ui.tab("Lua Examples")
local group = tab:group("Overlay")
local enabled = group:checkbox("Show example", true)

events.on("paint", function()
    if not enabled:get() then
        return
    end

    render.text(24, 90, color(255, 255, 255), "Enabled")
end)
Скрипт создаёт собственную вкладку Lua Examples с чекбоксом. Ссылка на элемент хранится в enabled, а :get() возвращает его текущее значение. Все элементы и их методы — в разделе Меню · ui.

Заметка

Встроенный редактор работает с UTF-8 и файлами до 256 КиБ. При сохранении через редактор полный путь к файлу вводить не нужно.

#
Контексты и типичные ошибки
Рисование (render.*) — только внутри paint.
Объект wl.cmd трогай только в своём createmove, wl.view — в override_view, wl.event — в своём обработчике события.
Трассировки trace.* и engine.simulate работают в createmove, frame_stage и колбэках игровых событий.
Запись памяти, ffi, http, file и часть методов требуют включённый Allow Insecure. Примеры из репозитория этот режим не используют.
Если скрипт не загружается — смотри текст ошибки в выводе Lua, проверь кодировку файла, имена функций и контекст вызова. Для отчёта о проблеме достаточно минимального кода и номера сборки.

02
Готовые примеры
Три минимальных скрипта из папки examples репозитория. Они не требуют Allow Insecure; запуск в игре авторами ещё не проверялся, но используют только задокументированные функции.

#
01 · Hello World — сообщения при загрузке и выгрузке
01_hello_world.lua
lua
Копировать
-- @author Example
-- @uid 1
-- Prints load/unload messages. Does not require Allow Insecure.

print("Hello from Neverlose Lua!")

events.on("unload", function()
    print("Hello World unloaded")
end)
print при загрузке подтверждает, что скрипт поднялся. Подписка на unload позволяет корректно «прибраться» перед выгрузкой — снять таймеры, закрыть сокеты, вывести прощальное сообщение.

#
02 · Оверлей — флажок в меню и плашка на экране
02_overlay.lua
lua
Копировать
-- @author Example
-- @uid 1
-- A checkbox and a small overlay. Does not require Allow Insecure.

local tab = ui.tab("Lua Examples")
local group = tab:group("Overlay")
local enabled = group:checkbox("Show example", true)
local tint = color(220, 230, 255, 255)

events.on("paint", function()
    if not enabled:get() then
        return
    end

    render.rect_filled(20, 80, 190, 35, color(15, 18, 25, 210), 6)
    render.text(30, 90, tint, "Neverlose Lua example")

Классический каркас любого оверлея: элемент меню управляет видимостью, а paint рисует подложку rect_filled (последний аргумент 6 — скругление углов) и текст поверх неё. Ранний return из колбэка — дешёвый способ выключить отрисовку.

03
Окружение и песочница
Скрипты выполняются на LuaJIT 2.1 (совместимость с Lua 5.1) внутри песочницы: часть стандартных библиотек вырезана, загрузка файлов и сети доступны только в insecure-режиме.

#
Что доступно из стандартной библиотеки
Модуль	Статус в песочнице
_G, table, string, math, bit, jit	доступны полностью
os	урезан: os.clock() (= globals.realtime), os.time(), os.date()
print(...)	пишет в вывод Lua через tostring
load, loadstring	заменены собственной реализацией клиента
require	своя реализация, кэш модулей в REGISTRY.wl_modules
ffi	доступен только при включённом Allow Insecure
io, debug, package	не загружаются
dofile, loadfile	равны nil

Папки на диске

Все пути — относительно C:\neverwin\.

#
Контексты вызова функций
Некоторые группы функций работают только внутри определённых колбэков. Вызов в другом месте бросает ошибку — это защита движка, а не баг скрипта.

Функции	Разрешённый контекст
render.* (рисование)	только внутри paint, иначе ошибка «render.* draws only inside a paint callback»
trace.*, engine.simulate	только в createmove, frame_stage и колбэках игровых событий
wl.cmd	только внутри своего createmove
wl.view	только внутри override_view
wl.event	только внутри своего колбэка события
правильный контекст для trace
lua
Копировать
-- trace.line НЕЛЬЗЯ вызывать в paint — только createmove
local last_visible = {}

events.on("createmove", function(cmd)
    local me = entity.local_pawn()
    if not me or not me:alive() then return end

    for _, e in ipairs(entity.players()) do
        local pawn = e.pawn
        if pawn and pawn:is_enemy() and pawn:alive() then
            local tr = trace.line(me:eye_position(), pawn:bone(6), me)
            last_visible[pawn:steam_id()] = tr.hit and tr.entity == pawn
        end
    end
end)

-- а в paint можно только рисовать уже посчитанное
events.on("paint", function()
    local y = 120
    for sid, vis in pairs(last_visible) do
        render.text(24, y, vis and color(120, 255, 170) or color(255, 120, 110),
            sid .. (vis and " — виден" or " — за стеной"))
        y = y + 18
    end
end)
Паттерн «посчитай и нарисуй»

Тяжёлые проверки (видимость, урон, трассировки) делай в createmove и складывай результат в таблицу, а paint пусть только рисует. Так скрипт не упирается в контекстные ограничения и не тормозит кадр.

04
События — events
Вся жизнь скрипта строится на подписках: клиент вызывает твои функции в нужные моменты — на отрисовке, на команде движения, на игровых событиях CS2.

events.on(name, fn)
events.on(name: string, fn: function) -> integer   -- id подписки
Подписывает функцию fn на событие name и возвращает числовой id — сохрани его, чтобы потом отписаться. Аргументы, которые получит колбэк, зависят от события (таблица ниже).

events.off(id)
events.off(id: integer) -> boolean   -- true, если подписка существовала
#
Все события
Событие	Аргументы колбэка	Когда вызывается
paint	—	каждый кадр отрисовки; единственный контекст для render.*
createmove	cmd: wl.cmd	каждая команда движения (движок → сервер)
frame_stage	stage: integer (stage.*)	стадии кадра: lagcomp, net_update_end, render_start
override_view	view: wl.view	перед построением кадра камеры
menu_toggled	open: boolean	открытие/закрытие меню клиента
level_init	map: string	загрузка карты (имя карты в аргументе)
level_shutdown	—	выход с карты / отключение
movement_hit	string, number, number	смысл аргументов не установлен (?)
player_esp	player: wl.entity, box: {left, top, right, bottom}	отрисовка ESP-бокса игрока
unload	—	выгрузка скрипта
любое игровое событие	ev: wl.event	player_hurt, player_death, bomb_planted и все остальные события CS2
#
Примеры подписок
жизненный цикл скрипта
lua
Копировать
-- 1. Отрисовка: текст в левом верхнем углу
events.on("paint", function()
    render.text(24, 90, color("#45d6b5"), "my script · " .. globals.tickcount())
end)

-- 2. Игровое событие: реагируем на урон
local hurt_id = events.on("player_hurt", function(ev)
    local victim = ev:get_pawn("userid")
    local attacker = ev:get_pawn("attacker")
    if victim and attacker and attacker:is_local() then
        log.chat("Минус ", ev:get_int("dmg_health"), " HP (осталось ", victim:health(), ")")
    end
end)

-- 3. Смена карты: сбрасываем накопленные данные
local stats = {}
events.on("level_init", function(map)
    stats = {}
    print("Зашли на карту: " .. map)
end)

-- 4. Отписка, когда обработчик больше не нужен
-- events.off(hurt_id)
Совет

Игровые события CS2 (player_hurt, player_death, round_start, bomb_planted…) подписываются тем же events.on — клиент проксирует их движок → Lua. Поля события читаются методами wl.event (get_int, get_string, get_pawn…).

05
Встроенные типы — vector, color, math, json, db
Прелюдия, которую клиент подмешивает в каждый скрипт до выполнения: конструкторы векторов и цветов, расширения math, JSON и маленькая JSON-база db. Исходники прелюдии приведены в приложении.

vector(x?, y?, z?)
vector(x?: number, y?: number, z?: number) -> vector   -- недостающие = 0
Создаёт таблицу {x, y, z} с метатаблицей. Перегружены операторы: + - * / (с вектором или числом — число применяется ко всем осям), унарный -, сравнение == и tostring.

операторы
lua
Копировать
local a = vector(10, 20, 30)
local b = vector(1, 2, 3)

print(a + b)       -- vector(11.000, 22.000, 33.000)
print(a * 2)       -- vector(20.000, 40.000, 60.000)
print(a == vector(10, 20, 30))  -- true
print(tostring(a)) -- vector(10.000, 20.000, 30.000)
Методы vector
Метод	Что делает
:length()	длина вектора
:length_sqr()	квадрат длины — быстрее, когда сравниваешь расстояния
:length2d()	длина без учёта z (по горизонтали)
:dist(o) / :dist2d(o)	расстояние до другого вектора
:dot(o)	скалярное произведение
:cross(o)	векторное произведение
:normalized()	вектор длины 1 того же направления (нулевой вернёт vector())
:clone()	копия вектора
:unpack()	возвращает три числа: x, y, z
:is_zero()	true, если все оси нулевые
:lerp(o, t)	линейная интерполяция к o на долю t
:forward()	вектор направления из углов: vector(pitch, yaw) → направление
:angle_vectors()	из углов (pitch, yaw, roll) → forward, right, up
:angles()	из направления → vector(pitch, yaw, 0)
геометрия на векторах
lua
Копировать
local me = entity.local_pawn()
local enemy = entity.players()[1].pawn

-- дистанция по земле (метры ≈ юниты / 39.37, но для сравнений хватает юнитов)
local d = me:origin():dist2d(enemy:origin())

-- углы, куда нужно смотреть, чтобы целиться в кость головы (6)
local head = enemy:bone(6)
local aim = math.calc_angle(me:eye_position(), head)

-- точка в 100 юнитах перед игроком
local ahead = me:origin() + me:eye_angles():forward() * 100
color(r?, g?, b?, a?) / color('#RRGGBB[AA]')
color(r?: number, g?: number, b?: number, a?: number) -> color
color(hex: string) -> color   -- "#RRGGBB" или "#RRGGBBAA"
Таблица {r, g, b, a}, каналы 0..255, по умолчанию 255. Форма с одним числом color(v) даёт серый (v, v, v). Все C-функции API читают цвет именно из полей r, g, b, a (значения обрезаются до 0..255, a по умолчанию 255), поэтому свою «цветоподобную» таблицу передать можно — но если передать не таблицу, получишь ошибку bad argument #N (a color is needed: color(r, g, b, a)).

Методы color
Метод	Что делает
:alpha(a)	копия с другой альфой
:lerp(o, t)	интерполяция к цвету o на долю t
:unpack()	четыре числа: r, g, b, a

Цвет из HSV-представления. Удобно для «радуги» по времени: color_hsv(globals.realtime() % 1, 1, 1).

color_percent(p: number, a?: number) -> color   -- p обрезается в 0..1
Готовый градиент «красный → зелёный» по проценту. Идеален для полосок HP: color_percent(hp / 100).

Расширения math
Функция	Что делает
math.clamp(v, lo, hi)	зажать v в диапазон [lo, hi]
math.lerp(a, b, t)	a + (b - a) * t
math.round(v)	округление до целого (floor(v + 0.5))
math.remap(v, a, b, c, d)	перенос v из [a, b] в [c, d]

плавное появление оверлея
lua
Копировать
local alpha = 0
local target = 1

events.on("paint", function()
    -- догоняем target со скоростью 8 долей в секунду
    alpha = math.lerp(alpha, target, math.clamp(globals.frametime() * 8, 0, 1))

    local c = color("#45d6b5"):alpha(alpha * 255)
    render.rect_filled(20, 80, 200, 40, color(15, 18, 25):alpha(alpha * 210), 8)
    render.text(32, 92, c, "fading panel")
end)
json
json.encode(v: any) -> string   -- вложенность не больше 200
json.decode(text: string) -> value | nil, err
json.null   -- метка JSON null (таблица-заглушка)
Чистый Lua-кодек без внешних зависимостей. decode при ошибке возвращает nil и текст ошибки — проверяй оба возвращаемых значения. NaN и ±inf кодируются как null.

encode / decode
lua
Копировать
local payload = json.encode({ name = "stats", kills = 12, headshots = 7, tags = {"ace", "clutch"} })
-- '{"name":"stats","kills":12,"headshots":7,"tags":["ace","clutch"]}'

local data, err = json.decode(payload)
if not data then
    print("JSON-ошибка: " .. tostring(err))
    return
end
print(data.kills) -- 12
db — маленькая JSON-база
db.save(name: string, value: any) -> boolean
db.load(name: string, default: any) -> value
Надстройка над db._read/db._write (после инициализации они обнуляются). Каждое имя — отдельный файл C:\neverwin\scripts\data\db\<имя>.json. В имени допустимы только буквы, цифры, _ и -.

сохранить статистику между сессиями
lua
Копировать
local stats = db.load("my_stats", { kills = 0, shots = 0, hits = 0 })

events.on("player_hurt", function(ev)
    local attacker = ev:get_pawn("attacker")
    if attacker and attacker:is_local() then
        stats.hits = stats.hits + 1
        db.save("my_stats", stats)
    end
end)

events.on("paint", function()
    local acc = stats.shots > 0 and math.round(stats.hits / stats.shots * 100) or 0
    render.text(24, 140, color(255, 255, 255),
        string.format("Точность сессий: %d%%", acc))
end)
Заметка

db — для небольших структур (настройки, статистика). Для больших или бинарных данных используй file.* из insecure-раздела.

06
Игроки и объекты — entity
Модуль для доступа к игровым объектам: локальный игрок, все игроки на карте, оружие, любые сущности по имени класса. В CS2 у игрока два объекта: controller (счёт, ник) и pawn (тело, здоровье, оружие).

#
Получение объектов
entity.local_pawn()
entity.local_pawn() -> wl.entity | nil
Локальный pawn — «тело» твоего игрока: здоровье, позиция, оружие. В меню/лобби равен nil.

entity.local_controller()
entity.local_controller() -> wl.entity | nil
Локальный контроллер — ник, деньги, статистика.

Отрисовка и ресурсы — render
Экранное 2D-API: примитивы, текст, текстуры, шрифты и масштабирование. Почти всё рисование живёт строго внутри paint; измеряющие функции (размеры текста, world_to_screen) работают где угодно.

Трассировки — trace
Лучи и объёмы против геометрии карты: видимость, прострелы, симуляция пуль и урон. Основа любого wall-чека и damage-индикатора.

Контекст

Всё, кроме trace.scale_damage и trace.smoke, работает только в createmove, frame_stage и колбэках игровых событий.

trace.line(from, to, opts?)
createmove · frame_stage · события
trace.line(from: vector, to: vector, opts?) -> result
-- opts: wl.entity (кого пропустить) | { skip, mask, layer, type, mins, maxs }
-- result: { hit, fraction, position, normal, entity, start_solid, friction, ... }
Луч из from в to. fraction — доля пройденного пути (1 = ничего не задето), position — точка удара, normal — нормаль поверхности, entity — сущность, в которую попали. В skip можно передать одного игрока или массив.

trace.hull(from, to, mins, maxs, opts?)
createmove · frame_stage · события
trace.hull(from, to: vector, mins, maxs: vector, opts?) -> result
Трассировка не лучом, а коробкой mins..maxs — проверка «пролезу ли в щель», «стою ли в дыму».

trace.bullet(from, to, target?, hitgroup?)
createmove · frame_stage · события
trace.bullet(from, to: vector, target?: wl.entity, hitgroup?: int) -> { hit, entity, damage, penetrated, position, range, target_damage, target_hit }
Полная симуляция выстрела: урон с учётом брони, прострелов и дистанции — тем же кодом, что стреляет игра.

trace.damage(target, pos, hitgroup?, from?)
trace.damage(target: wl.entity, pos: vector, hitgroup?: int, from?: vector) -> number
Сколько урона получит target от выстрела в точку pos (хитгруппа и точка выстрела уточняются).

trace.can_penetrate(from, to)
trace.can_penetrate(from, to: vector) -> boolean
Простреливаемо ли пространство между точками (без точного урона — быстрее trace.bullet).

trace.scale_damage(damage, hitgroup, target)
любой контекст
trace.scale_damage(damage: number, hitgroup: int, target: wl.entity) -> number
Применяет множители хитгруппы и брони к «сырому» урону.

trace.smoke(from, to)
любой контекст
trace.smoke(from, to: vector) -> boolean, number
Перекрывает ли дымовую гранату линия from → to; вторым числом — «плотность» перекрытия.

trace.mask — константы масок
trace.mask.visible = 1847299
trace.mask.shot    = 1847307
trace.mask.player  = 1839107
Готовые битовые маски: что считать «стеной» для луча. shot учитывает всё, что останавливает пулю.

Копировать

    local me = entity.local_pawn()

        if pawn and pawn:alive() and pawn:is_enemy() then

            if head then
                local res = trace.bullet(from, head, pawn)
                cache[pawn:steam_id()] = res.hit and res.damage or 0
            end
        end
    end
end)

        if dmg > 0 then

    local me = entity.local_pawn()

Insecure API
Возможности, доступные только при включённом Allow Insecure на странице Lua: сырая память, файлы, сеть, хуки и LuaJIT FFI. Это мощный, но «громкий» режим — клиент в нём заметнее для античита.

Прежде чем включать

Клиент выполняет три куска Lua ещё до твоего скрипта: прелюдию с vector/color/math/json, обёртку db и обёртку hooks.add. Полные тексты — в reference.md; ниже — самое поучительное.

B.2 · как устроен db
обёртка db (в оригинале — одной строкой)
lua
Копировать
local read, write = db._read, db._write
db._read, db._write = nil, nil   -- спрятать сырые функции от скриптов

function db.save(name, value)
    return write(name, json.encode(value))
end

function db.load(name, default)
    local text = read(name)
    if not text then return default end
    local value = json.decode(text)
    if value == nil then return default end
    return value
end
Обрати внимание: сырые db._read/db._write обнуляются после инициализации — наружу торчит только безопасная пара save/load.

B.3 · обёртка hooks.add
Lua-обёртка перехвата
lua
Копировать
local raw = hooks.add
local keep = {}

hooks.add = function(target, a, b)
    if type(a) ~= 'string' then
        return raw(target, a)           -- низкоуровневая форма
    end
    local callback = ffi.cast(a, b)     -- ctype → C-колбэк
    local hook = raw(target, callback)
    keep[hook] = callback               -- не дать GC убить колбэк
    return hook, ffi.cast(a, hook:original())
end
Таблица keep решает классическую проблему FFI: если не держать ссылку на ffi.cast-колбэк, сборщик мусора освободит его — и игра упадёт при первом же вызове хука.

B.1 · прелюдия vector / color / math / json
Полный исходник (~250 строк чистой Lua 5.1) лежит в спецификации. Несколько выводов, которые из него следуют:

векторы и цвета — обычные таблицы с метатаблицами, поэтому свои «цвета» можно собирать руками: setmetatable({r=255,g=0,b=0,a=255}, {}) тоже сработает в render.*;
операторы векторов принимают и число, и вектор: vector(1,2,3) * 2 и vector(1,2,3) * vector(4,5,6) — оба валидны;
в json.encode массивом считается таблица с подряд идущими числовыми ключами; смешанные таблицы сериализуются как объекты;
NaN и ±inf в JSON превращаются в null — не теряй их молча.

Ошибки и FAQ
Сообщения, которые скрипт может бросить, — с причинами и лечением. Если своей ошибки здесь нет, открой Issue с минимальным примером и номером сборки.

#
Расшифровка ошибок
render.* draws only inside a paint callback

Почему: Функция рисования вызвана вне события paint — например, прямо в теле скрипта или в createmove.

Что делать: Перенеси вызов внутрь events.on("paint", ...). Тяжёлые расчёты оставь в createmove, в paint — только рисование.

bad argument #N (a color is needed: color(r, g, b, a))

Почему: В render.* передано число, строка или nil вместо цвета — часто из-за перепутанного порядка аргументов.

Что делать: Проверь сигнатуру: цвет всегда идёт после координат. Собери color(...) заранее в переменную и проинспектируй её print'ом.

schema: no field <class>::<field>

Почему: Поля с таким именем нет в сетевой схеме этого класса — опечатка или поле живёт в родительском/другом классе.

Что делать: Проверь имя класса (entity:class_name()) и имя поля. Для разведки путей настроек есть config.keys(prefix).

script does not own this element

Почему: Ты вызвал метод изменения (set_name, import, chip…) на элементе основного меню, найденном через ui.find.

Что делать: Эти методы работают только на элементах, созданных скриптом (ui.checkbox и т.п.). Родные элементы — только чтение и set_value.

option is not a color picker / chips can only be added to entity elements

Почему: Метод применён к элементу неподходящего типа.

Что делать: Проверь тип через wl.menu_control:get_type() перед вызовом.

too many requests running

Почему: Превышен лимит одновременных http-запросов скрипта.

Что делать: Дождись колбэка предыдущего запроса или ставь запросы в очередь через client.delay.

no such icon

Почему: Имени иконки нет во встроенном наборе.

Что делать: Список всех имён — render.icons().

cannot open (file.read)

Почему: Файл не найден. Пути file.* считаются от C:\neverwin\scripts\data.

Что делать: Проверь file.exists() и регистр имени; абсолютные пути не поддерживаются.

json.decode: trailing characters at N

Почему: После валидного JSON в строке есть мусор — например, два объекта подряд или BOM.

Что делать: Пиши в файл только результат json.encode и читай целиком.

Скрипт не появляется / не загружается

Почему: Кодировка не UTF-8, файл больше 256 КиБ, синтаксическая ошибка или выключен нужный режим.

Что делать: Сохрани как UTF-8 без BOM, смотри текст ошибки в выводе Lua. Для ffi/memory/http/file включи Allow Insecure.

Частые вопросы
Вопрос	Ответ
Куда класть скрипты?	В C:\neverwin\scripts (или создать через Extensions → +). Ресурсы — в подпапках images / fonts / particles / data.
Чем db отличается от file?	db — именованные JSON-значения «из коробки», file — произвольные файлы (и требует insecure).
Как перезагрузить скрипт при разработке?	Кнопка Reload в Extensions или client.reload() из самого скрипта.
Почему render.* нельзя в createmove?	Кадр ещё не строится — рисовать физически некуда. Посчитай данные в createmove, нарисуй в paint.
Что такое wl.* в сигнатурах?	Внутренние имена типов объектов (wl.entity, wl.ui, wl.cmd…). В коде ты их не пишешь — просто получаешь из функций.
Сколько всего можно создать?	До 64 вкладок на скрипт, до 64 хуков, до 256 текстур. Лимит одновременных http-запросов — небольшой, ставь очередь.
Можно ли писать на Lua 5.3/5.4?	Нет — рантайм LuaJIT 2.1 совместим с Lua 5.1: нет целочисленного деления //, битовых операторов & | ~ и goto-меток в стиле 5.2+. Биты — через библиотеку bit.
Как сообщить о неточности в справочнике?	Issue на GitHub: минимальный пример, версия сборки, текст ошибки, ожидаемый результат.
Чек-лист здорового скрипта

1) всё рисование — в paint; 2) трассировки — в createmove; 3) wl.cmd/wl.view/wl.event не покидают своих колбэков; 4) текстуры и шрифты загружаются один раз; 5) в unload снимаются esp-элементы, бинды, хуки и восстановленные cvar; 6) client.insecure() проверяется до insecure-вызовов.
